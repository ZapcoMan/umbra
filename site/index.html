IP 地理定位

当前版本 v0.1.0 Apache-2.0 OR MIT IPv4 + IPv6 离线库

UMBRA 把 IP 地理位置数据编译为本地 .xdb 文件，查询全程在本机完成， 不联网、不上传。同时支持 IPv4 / IPv6，数据访问统一由 Rust 内核实现。

下载桌面版 命令行 30 秒上手 
$ umbra 8.8.8.8 2408:4003::1
  8.8.8.8       │ United States|California|0|Google LLC|US
  2408:4003::1  │ 中国|广东省|深圳市|阿里|CN

核心特性

完全离线

内置 ip2region v4/v6 xdb，查询不产生任何网络请求，隐私零外泄。

Rust 内核

数据解析、双栈路由、region 结构化全在 umbra-core，前端只做界面。

三种形态

桌面客户端、命令行工具、网页端 + HTTP API，一套内核多端复用。

三主题界面

极客 / 暗色 / 亮色主题，设置页一键切换并本地持久化。

IPv4 + IPv6

自动按地址族路由到对应库，批量查询逐项独立不中断。

结构化输出

region 解析为 国家 / 省份 / 城市 / ISP / ISO 五段，缺失以 0 标注。

三种形态

◐ 桌面客户端

Tauri 2 + Vue3 + Element Plus，Windows 安装包（MSI / NSIS）。经 IPC 调用 Rust 内核，本地离线查询。

>_ 命令行

umbra：单 IP、管道批量、NDJSON 输出、--db-dir 指定数据。适合脚本与集成。

🌐 网页端 + API

umbra-server 提供 HTTP 查询 API（三层 controller/service/mapper），网页端经其取数。

快速上手

# 命令行：查询单个或批量 IP
umbra 8.8.8.8 114.114.114.114
cat ips.txt | umbra --json

# HTTP API（由 Rust 内核离线解析）
curl "http://127.0.0.1:8080/api/lookup?ip=8.8.8.8"
# {"ok":true,"ip":"8.8.8.8","region":{...}}

使用须知

  • IP 地理数据由第三方渠道汇总，精度与时效有限，不作为高置信场景唯一依据。
  • 请在符合所在地法律法规的前提下使用，不得用于侵犯他人隐私或其他违法违规用途。
  • UMBRA 所有查询均在本机离线完成，不会向任何外部服务发送你查询的 IP。
